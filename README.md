
# Atlas OS

**A personal productivity app for managing your time, staying focused, and building better daily habits.**

Atlas OS pulls a handful of productivity tools into one place, so you're not juggling a different app for every part of your day. I built it with AI-assisted "vibe coding," and I'm still shaping it as I go.

## What it does

- **Pomodoro timer:** work in focused sprints with short breaks in between, based on the classic Pomodoro technique.
- **Productivity tools:** a growing set of extras for staying organized and keeping your day on track.

I'm documenting each feature in detail as I verify it, so expect this section to grow.

## Built with

The repo includes HTML, JavaScript, Electron, Capacitor, Python, and Node.js project configuration.

## Privacy

Atlas OS is a personal productivity tool, and I want to be upfront about your data:

- **No account needed.** You don't have to sign up or log in to use it.
- **Your data stays on your device.** Your timers, settings, and other app data are stored locally, not on a server of mine.
- **No tracking or ads.** I don't collect analytics, sell data, or show ads.
- **Third-party services.** If a future version adds any online feature, I'll document it here first.
